❓ Common Questions

Q: What does this workflow do?
A: Automates ticket triage, response drafting, and knowledge base search to save agents ~15 minutes per ticket.

Q: Do I need Claude.ai to use this?
A: For implementation, yes (Claude API). But the documentation and dashboard work without login.

Q: How long does setup take?
A: 2-3 hours for infrastructure + 15 min per agent training + 1 week soft launch = Live in ~2 weeks.

Q: Can I customize this?
A: Yes! Everything is markdown and templates. Edit freely for your company.

Q: Where are the Python scripts?
A: Coming in v1.1. For now, the docs tell you exactly what each script does.
